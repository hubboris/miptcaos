# Выравнивание адреса

## 📝 Условие
Процессор быстрее читает данные, адрес которых выровнен, то есть кратен размеру выравнивания (например, 8 байт).

Считайте адрес `addr` и выравнивание `align` (положительные числа). Выведите, выровнен ли адрес, а также ближайший выровненный адрес вниз и вверх.

Напишите программу на C в файле `solution.c`.

## 📥 Формат ввода
Одна строка: два положительных целых числа `addr` и `align` через пробел. Числа помещаются в `unsigned long long`, переполнения при вычислениях в тестах нет.

## 📤 Формат вывода
Три строки:
```
Aligned: yes|no
Down: <ближайший выровненный адрес вниз>
Up: <ближайший выровненный адрес вверх>
```
Если адрес уже выровнен, то `Down` и `Up` равны `addr`.

## 💡 Пример
Ввод:
```
13 8
```
Вывод:
```
Aligned: no
Down: 8
Up: 16
```

Ввод:
```
24 8
```
Вывод:
```
Aligned: yes
Down: 24
Up: 24
```

## ⚙️ Быстрая сборка и тесты
```bash

echo "13 8" | ./solution                   # запустить
pytest tests                               # запустить тесты
```
