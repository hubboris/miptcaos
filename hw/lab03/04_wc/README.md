# Упрощённый аналог wc

## 📝 Условие
Напишите упрощённый аналог утилиты `wc`. Программа читает символы из стандартного ввода до `EOF` и выводит количество символов, слов и строк.

Слово — это последовательность символов без пробелов, табуляций и переводов строки.

Напишите программу на C в файле `solution.c`. Сборка выполняется через `Makefile` (цель `all` создаёт исполняемый файл `solution`, цель `clean` его удаляет).

## 📥 Формат ввода
Произвольный текст из стандартного ввода (возможно, пустой), читается до `EOF`.

## 📤 Формат вывода
Три строки:
```
Chars: <количество символов>
Words: <количество слов>
Lines: <количество строк>
```
- Символ — один прочитанный байт (включая пробелы, табуляции и переводы строки).
- Количество строк равно количеству символов перевода строки `\n` во вводе (как в `wc -l`).

## 💡 Пример
Ввод:
```
hello world
foo
```
(текст заканчивается переводом строки)

Вывод:
```
Chars: 16
Words: 3
Lines: 2
```

Пустой ввод:
```
Chars: 0
Words: 0
Lines: 0
```

## ⚙️ Быстрая сборка и тесты
```bash
make                                       # собрать программу
printf 'hello world\nfoo\n' | ./solution  # запустить
pytest tests                               # запустить тесты
make clean                                 # удалить бинарный файл
```
