# НДС в копейках

## 📝 Условие
В кассовых устройствах деньги хранят в целых копейках, чтобы не терять точность на вещественных числах.

Считайте цену товара в копейках (целое неотрицательное число) и вычислите НДС 20% с математическим округлением до целой копейки (0,5 и больше округляется вверх). Выведите НДС и итоговую сумму, используя только целые числа.

Напишите программу на C в файле `solution.c`. Сборка выполняется через `Makefile` (цель `all` создаёт исполняемый файл `solution`, цель `clean` его удаляет).

## 📥 Формат ввода
Одна строка: целое число `price` — цена в копейках, `0 ≤ price ≤ 10^15`.

## 📤 Формат вывода
Две строки:
```
VAT: <НДС в копейках>
Total: <цена + НДС в копейках>
```

## 💡 Пример
Ввод:
```
1999
```
Вывод:
```
VAT: 400
Total: 2399
```

Ввод:
```
3
```
Вывод:
```
VAT: 1
Total: 4
```

## ⚙️ Быстрая сборка и тесты
```bash
make                                       # собрать программу
echo "1999" | ./solution                   # запустить
pytest tests                               # запустить тесты
make clean                                 # удалить бинарный файл
```
