# Обратный порядок байт

## 📝 Условие
Сетевой порядок байт (big-endian) отличается от порядка в памяти большинства процессоров (little-endian).

Считайте 32-битное беззнаковое число и выведите число, у которого порядок байт обратный. Например, `0x12345678` превращается в `0x78563412`. Выведите результат в десятичном и шестнадцатеричном виде.

Напишите программу на C в файле `solution.c`. Сборка выполняется через `Makefile` (цель `all` создаёт исполняемый файл `solution`, цель `clean` его удаляет).

## 📥 Формат ввода
Одна строка: целое число от `0` до `4294967295` в десятичной записи.

## 📤 Формат вывода
Две строки:
```
Decimal: <результат в десятичном виде>
Hex: 0x<результат в шестнадцатеричном виде>
```
Шестнадцатеричная запись состоит ровно из 8 цифр (с ведущими нулями), буквы `A`–`F` заглавные.

## 💡 Пример
Ввод (`0x12345678`):
```
305419896
```
Вывод (`0x78563412`):
```
Decimal: 2018915346
Hex: 0x78563412
```

Ввод:
```
1
```
Вывод:
```
Decimal: 16777216
Hex: 0x01000000
```

## ⚙️ Быстрая сборка и тесты
```bash
make                                       # собрать программу
echo "305419896" | ./solution              # запустить
pytest tests                               # запустить тесты
make clean                                 # удалить бинарный файл
```
