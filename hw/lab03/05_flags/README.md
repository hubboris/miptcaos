# Эмулятор регистра флагов

## 📝 Условие
В драйверах состояние устройства хранят в одном байте, где каждый бит — отдельный флаг.

Напишите эмулятор регистра флагов (8 бит, изначально `0`). Команды:
- `1 n` — установить бит `n` (0–7);
- `2 n` — сбросить бит `n`;
- `3 n` — инвертировать бит `n`;
- `4` — вывести регистр в виде 8 двоичных цифр;
- `0` — завершить программу.

Напишите программу на C в файле `solution.c`. Сборка выполняется через `Makefile` (цель `all` создаёт исполняемый файл `solution`, цель `clean` его удаляет).

## 📥 Формат ввода
Последовательность команд из стандартного ввода, числа разделены пробелами или переводами строк. Бит `0` — младший. Чтение заканчивается командой `0` (или концом ввода). Номер бита всегда от `0` до `7`.

## 📤 Формат вывода
На каждую команду `4` выводится одна строка из 8 символов `0` и `1`: слева старший бит (`7`), справа младший (`0`). Другие команды ничего не выводят.

## 💡 Пример
Ввод:
```
1 0
1 3
4
3 0
4
2 3
4
0
```
Вывод:
```
00001001
00001000
00000000
```

## ⚙️ Быстрая сборка и тесты
```bash
make                                       # собрать программу
printf '1 0\n1 3\n4\n0\n' | ./solution    # запустить
pytest tests                               # запустить тесты
make clean                                 # удалить бинарный файл
```
