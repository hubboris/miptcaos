# Переполнение при умножении

## 📝 Условие
В системном ПО часто считают размер буфера как `количество * размер_элемента`, и переполнение при умножении приводит к уязвимостям.

Считайте два числа типа `int` и определите, приведёт ли их умножение к переполнению `int`. Если нет, выведите произведение.

Напишите программу на C в файле `solution.c`. Сборка выполняется через `Makefile` (цель `all` создаёт исполняемый файл `solution`, цель `clean` его удаляет).

## 📥 Формат ввода
Одна строка: два целых числа `a` и `b` через пробел. Оба числа помещаются в `int` (могут быть отрицательными и нулём).

## 📤 Формат вывода
Одна строка:
- `Overflow`, если произведение `a * b` не помещается в `int`;
- `Product: <a * b>` в остальных случаях.

## 💡 Пример
Ввод:
```
1000 1000
```
Вывод:
```
Product: 1000000
```

Ввод:
```
100000 100000
```
Вывод:
```
Overflow
```

## ⚙️ Быстрая сборка и тесты
```bash
make                                       # собрать программу
echo "1000 1000" | ./solution              # запустить
pytest tests                               # запустить тесты
make clean                                 # удалить бинарный файл
```
