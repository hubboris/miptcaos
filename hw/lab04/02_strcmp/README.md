# Аналог strcmp на арифметике указателей

## 📝 Условие
Напишите аналог функции `strcmp`, используя только арифметику указателей (без `[]`). Функция возвращает `0`, если строки равны, отрицательное число, если первая строка меньше, и положительное, если больше. Проверьте на нескольких парах строк.

Сравнение посимвольное, как в стандартной `strcmp`: символы сравниваются как `unsigned char`, строка, которая является префиксом другой, считается меньшей.

Файлы `main.c` (читает пары строк и вызывает вашу функцию), `my_strcmp.h` и `Makefile` уже даны, менять их не нужно. Вам нужно написать функцию в файле `my_strcmp.c`:
```c
int my_strcmp(const char *a, const char *b);
```

Требования к `my_strcmp.c`:
- нигде не используются квадратные скобки `[` и `]`;
- не подключается `<string.h>` и не вызываются `strcmp`, `strncmp`, `memcmp`.

## 📥 Формат ввода (для `main.c`)
Первая строка — число пар `n`. Далее `2n` строк: `n` пар строк, каждая строка занимает отдельную строку ввода (может быть пустой и содержать пробелы). Длина строки не превышает 1000 символов.

## 📤 Формат вывода
Для каждой пары одна строка:
- `less` — первая строка меньше второй;
- `equal` — строки равны;
- `greater` — первая строка больше второй.

## 💡 Пример
Ввод:
```
4
apple
apple
apple
banana
b
a
abc
ab
```
Вывод:
```
equal
less
greater
greater
```
