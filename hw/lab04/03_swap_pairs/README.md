# Обмен соседних элементов массива

## 📝 Условие
Дан массив целых чисел на стеке. Не выделяя дополнительной памяти и используя указатели, поменяйте местами соседние пары элементов (`1 2 3 4 5 6` → `2 1 4 3 6 5`). Если длина нечётная, последний элемент остаётся на месте.

Файлы `main.c` (читает массив, размещает его на стеке, вызывает вашу функцию и печатает результат), `swap_pairs.h` и `Makefile` уже даны, менять их не нужно. Вам нужно написать функцию в файле `swap_pairs.c`:
```c
void swap_pairs(int *arr, int n);
```

Требования к `swap_pairs.c`:
- нигде не используются квадратные скобки `[` и `]`: работа ведётся только через указатели;
- не выделяется динамическая память (`malloc`, `calloc`, `realloc`, `alloca`) и не создаётся второй массив;
- не подключаются `<string.h>` и `<stdlib.h>`, не вызываются `memcpy`, `memmove` и подобные функции;
- функция не должна обращаться к памяти за пределами массива (`main.c` это проверяет).

## 📥 Формат ввода (для `main.c`)
Первая строка — длина массива `n` (`0 ≤ n ≤ 1000`). Далее `n` целых чисел типа `int`, разделённых пробелами или переводами строк.

## 📤 Формат вывода
Одна строка: элементы массива после обмена, через пробел. Для `n = 0` выводится пустая строка.

## 💡 Пример
Ввод:
```
6
1 2 3 4 5 6
```
Вывод:
```
2 1 4 3 6 5
```

Ввод:
```
5
10 20 30 40 50
```
Вывод:
```
20 10 40 30 50
```
