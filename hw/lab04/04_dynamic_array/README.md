# Динамический массив чётных чисел

## 📝 Условие
Программа читает целые числа из стандартного ввода **до первого отрицательного числа** (само отрицательное число в обработке не участвует) и сохраняет в динамический массив только **чётные** числа в порядке чтения. Число `0` чётное, поэтому сохраняется. В конце программа выводит сохранённые числа, их количество и текущую ёмкость массива, после чего освобождает память.

Массив должен расширяться по мере необходимости:
- начальная ёмкость — **4 элемента**;
- когда массив заполнен и нужно добавить ещё один элемент, ёмкость **удваивается** (4 → 8 → 16 → …) с помощью `realloc`;
- память выделяется в куче, фиксированный массив большого размера использовать нельзя.

Файлы `main.c` (чтение чисел, фильтрация, вывод), `int_vec.h` (описание структуры и функций) и `Makefile` уже даны, менять их не нужно. Вам нужно реализовать три функции в файле `int_vec.c`:

```c
void vec_init(IntVec *v);          // пустой массив, выделить память на 4 элемента
int  vec_push(IntVec *v, int x);   // добавить x в конец, при необходимости удвоить ёмкость
void vec_free(IntVec *v);          // освободить память и обнулить поля
```

Подробные контракты функций описаны в комментариях к `int_vec.h`.

Требования:
- рост ёмкости выполняется через `realloc`;
- если `realloc` вернул `NULL`, `vec_push` возвращает `-1`, а ранее сохранённые данные не теряются;
- после работы программы не должно быть утечек памяти, двойного `free` и выходов за границы массива (тесты запускают программу под `AddressSanitizer`).

## 📥 Формат ввода
Целые числа типа `int`, разделённые пробелами или переводами строк. Чтение заканчивается на первом отрицательном числе (все числа после него игнорируются) либо на конце ввода, если отрицательных чисел нет. Чисел может быть до нескольких сотен тысяч.

## 📤 Формат вывода
Три строки:
```
<сохранённые числа через пробел (пустая строка, если таких нет)>
Count: <количество сохранённых чисел>
Capacity: <ёмкость массива в конце работы>
```

## 💡 Примеры
Ввод:
```
3 8 15 4 0 7 10 -1 6
```
Вывод:
```
8 4 0 10
Count: 4
Capacity: 4
```
(число `6` стоит после отрицательного, поэтому не читается)

Ввод:
```
2 4 6 8 10 12 -5
```
Вывод:
```
2 4 6 8 10 12
Count: 6
Capacity: 8
```
(на пятом чётном числе массив был заполнен, и ёмкость выросла с 4 до 8)

Ввод:
```
-1
```
Вывод:
```

Count: 0
Capacity: 4
```
(первая строка пустая)

## ⚙️ Быстрая сборка и тесты
```bash
make                                       # собрать программу
echo "2 4 6 8 10 -1" | ./solution          # запустить
make asan                                  # собрать с проверкой памяти (solution_asan)
echo "2 4 6 8 10 -1" | ./solution_asan     # запустить с проверкой памяти
pytest tests                               # запустить тесты
make clean                                 # удалить бинарные файлы
```
