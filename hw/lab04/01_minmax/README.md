# Максимум и минимум из аргументов командной строки

## 📝 Условие
Напишите программу, которая принимает через аргументы командной строки произвольное количество целых чисел и выводит их максимум и минимум.

Если аргументы не переданы, выведите справочное сообщение. Некорректные аргументы (не числа) пропускайте с предупреждением.

Напишите программу на C в файле `solution.c`. Сборка выполняется через `Makefile` (цель `all` создаёт исполняемый файл `solution`, цель `clean` его удаляет).

## 📥 Формат ввода
Числа передаются в аргументах командной строки: `./solution a1 a2 ... an`. Стандартный ввод не используется.

Аргумент считается корректным, если это целое число в десятичной записи (допускается знак `+` или `-` перед цифрами), которое помещается в `long long`. Всё остальное (`abc`, `12abc`, `1.5`, пустая строка, слишком большое по модулю число) — некорректный аргумент.

## 📤 Формат вывода
Если среди аргументов есть хотя бы одно корректное число, в стандартный вывод две строки:
```
Max: <максимум>
Min: <минимум>
```

Для каждого некорректного аргумента в **стандартный поток ошибок** выводится предупреждение (в порядке следования аргументов):
```
Warning: skipping invalid argument "<аргумент>"
```

Если аргументов нет или ни один из них не корректен, в стандартный вывод выводится справочное сообщение (одна строка):
```
Usage: <имя программы> <integer> [integer ...]
```
`<имя программы>` — `argv[0]`.

Во всех случаях программа завершается с кодом `0`.

## 💡 Пример
```bash
$ ./solution 3 -7 12 0
Max: 12
Min: -7

$ ./solution 5 abc 9 1.5
Warning: skipping invalid argument "abc"
Warning: skipping invalid argument "1.5"
Max: 9
Min: 5

$ ./solution
Usage: ./solution <integer> [integer ...]
```
(предупреждения идут в `stderr`, поэтому в терминале они могут оказаться среди остального вывода)

## ⚙️ Быстрая сборка и тесты
```bash
make                                       # собрать программу
./solution 3 -7 12 0                       # запустить
pytest tests                               # запустить тесты
make clean                                 # удалить бинарный файл
```
